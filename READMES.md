Project name =  bazar-dor

Description
A price tracking web application that displays daily product prices, compares price changes over time, and allows users to browse products by category and sort them by price.

Technologies used
git 
1. React
2. TypeScript
3. Tailwind CSS
4. REST API
5. JavaScript (ES6+)
6. BettAuth
7. Mongodb atlas
8. daisyUI

5 key features of the project

1. Daily Price Tracking – View the latest prices of everyday products.
2. Price Comparison – Compare current prices with yesterday, last week, and last month.
3. Category-Based Browsing – Explore products organized by category.
4. Price Sorting – Sort products from lowest to highest or highest to lowest price.
5. Market Price Comparison – Compare minimum and maximum prices across different markets.
